## 3. 每个模块如何算完成

| 模块 | 输入与输出 | 必须验收的行为 |
| --- | --- | --- |
| M1 | 表结构、记录、RID -> 持久化页和记录 | 多页读写、重开、类型与主键校验、稳定 RID、错误后原数据保留 |
| M2 | 页请求 -> 页副本及 I/O 指标 | LRU 淘汰顺序正确；脏页正确写回；写回失败不丢脏数据；已有 M1 测试仍通过 |
| M3 | SQL 文本 + Catalog -> 语法树和合法计划 | 字符串内关键字不误分割；错误定位；空表也校验字段；歧义列明确报错 |
| M4 | 计划 + 存储接口 -> 行集合 | 扫描、过滤、投影、连接、排序正确；写入失败不留下部分语句修改；重复行不丢失 |
| M5 | 索引键/查询计划 -> RID/优化计划 | 分裂、重复键、范围、重启后索引正确；增删改维护一致；优化开关语义不变 |
| M6 | 身份 + 请求 -> 授权响应及审计 | 未登录不默认为管理员；越权拒绝；审计不泄露密码；UI 错误、空结果、大结果状态可用 |
| M7 | 事务命令/测试与实验 -> 状态变化/报告 | 回滚恢复数据与索引但保留审计；其他会话不能结束当前事务；报告数据可追溯 |

所有模块都提交：实现代码、独立测试、接口说明、至少一个失败场景、可以现场讲解的演示。模块已编码和已经组内验收是两个状态。

## 4. 优化对比实验规则

1. 使用同一数据集、SQL、缓冲池容量，并记录数据量、索引状态和程序版本。
2. 不带 ORDER BY 的结果按多重集比较，保留重复行；带 ORDER BY 则按已声明的排序语义验证，避免把并列键顺序当成错误。
3. 区分数据页逻辑读取、实际经磁盘层读取、索引读取、元数据读取。未统计的部分明确写出，不将局部计数称为总磁盘 I/O。
4. 冷缓冲与热缓冲分开测量；清空程序缓冲池不等于清空操作系统文件缓存。
5. 时间指标说明是否包括解析、规划、索引加载、执行、序列化。交替执行 ON/OFF，多次重复，保留原始值并展示中位数。
6. 选择等值索引查询、范围查询、选择性低的查询和连接查询；不预设所有优化都会更快，也不把毫秒级时间当作稳定测试断言。

上述是 M5/M7 的验收协议，目前尚未实现实验运行器。
